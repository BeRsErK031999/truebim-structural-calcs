# Шаблон verified case

Этот каталог содержит заготовку для первого проверенного случая продавливания по СП63. Шаблон не является расчетным эталоном: поля `expected` намеренно оставлены `null`, а `status` должен оставаться `draft`, пока инженер не предоставит проверенные значения.

## Как использовать

1. Скопируйте структуру из `verifiedCenterCase.template.ts` или из `examples/verification/center-verified-case.example.json`.
2. Заполните `input` теми же исходными данными, которые передаются в инженерный расчет.
3. Получите `expected` из доверенного источника: ручной расчет, webcad, проверенный Excel или нормативный пример.
4. Укажите источник в `source`. Для verified case строка должна содержать marker `manual`, `webcad`, `excel` или `нормативный пример`.
5. Поставьте `status: "verified"` только после заполнения всех expected values числами и инженерной проверки.
6. Проверьте JSON командой:

```powershell
npm run verification:validate -- path\to\verified-case.json
```

Скрипт только валидирует файл и не меняет dataset автоматически.
