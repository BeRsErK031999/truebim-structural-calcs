# Evidence Template Pack

Набор шаблонов для инженера-конструктора, который возвращает trusted evidence по расчету продавливания.

Файлы:

- `engineer-notes-template.md` - общие заметки инженера;
- `webcad-comparison-template.md` - сверка с WebCAD;
- `manual-calculation-template.md` - ручной расчет;
- `excel-verification-template.md` - сверка с Excel;
- `candidate-return-instructions.md` - что вернуть разработчику вместе с verification candidate.

Как использовать:

1. Скопируйте нужный шаблон.
2. Заполните поля без удаления предупреждений.
3. Приложите report, review snapshot, candidate JSON и исходные файлы evidence.
4. Не называйте candidate verified case. Candidate остается staging JSON до manual import и verification runner.
